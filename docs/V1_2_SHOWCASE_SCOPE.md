# E.X Galaxy v1.2 Showcase+ — Phase 1 Scope

## Scope correction

The Core Activation demonstration is now limited to the Video Studio / Autopilot Creative Orbit Auto Create sphere. Galaxy Hero, Camera, Spatial Canvas behavior and the 900ms / 560ms transition remain unchanged.

## Delivered

- Four-locale interface foundation and persisted locale selection
- Account and membership showcase
- E.X Credits balance, allocation, history, and demo actions
- Free / Creator / Enterprise pricing preview without production prices
- Enterprise inquiry demo
- Mock platform adapter foundation, backend reservation, and feature flags
- Mobile-responsive glass panels and static GitHub Pages compatibility
- Core Activation Sequence recreated through Zustand, CSS fallback, and optional R3F spatial depth; local motion references remain build-excluded

## Explicitly excluded

- Real authentication or user records
- Payments, checkout, financial charges, invoices, or billing server
- Cloud database, production API, analytics, or external Enterprise submission
- SSR, server-only routes, and runtime filesystem dependencies
- Changes to the v1.1.5 3D Spatial Layer, Camera, transition schedule, fallback, or Presentation baseline

## Phase 2 gate

Future work requires a new approved scope and version increment. Any remote adapter must remain disabled until backend contracts and commercial policy are approved.
