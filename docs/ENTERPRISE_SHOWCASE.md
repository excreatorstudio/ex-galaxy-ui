# Enterprise Showcase — v1.2 Phase 1

The Enterprise Foundation panel presents Team Workspace, Shared Credits, Organization Admin, Permission Roles, Custom AI Workflow, Private Asset Library, API / Integration, Private Deployment, and Dedicated Support.

The Contact Enterprise form collects Company, Name, Email, Team Size, and Use Case only in browser memory. Submit returns the localized confirmation: “Request captured in demo mode.” It does not transmit or persist data outside the current mock session.

The panel is responsive: desktop uses a right-side glass console; mobile uses a viewport-bounded bottom-sheet-style console with 44px-or-better controls and a vertical plan layout.
